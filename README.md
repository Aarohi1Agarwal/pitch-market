# PitchMarket

A clean static multi-page version of PitchMarket.

## Files

- `index.html` — public market homepage
- `products/foodoil-iq.html`
- `products/ecobottle.html`
- `products/smart-hostel.html`
- `products/farmsense.html`
- `products/meditrack.html`
- `products/studyai.html`
- `style.css` — all styling
- `app.js` — market, portfolio and investment logic

## Run locally

Open `index.html` with a local server such as VS Code Live Server.

## Important

This version is a static public website. Each visitor gets their own virtual balance and portfolio through browser `localStorage`.

If you want every visitor to see the same live investment totals, you need a backend/database. The frontend is ready to be connected to one later.
